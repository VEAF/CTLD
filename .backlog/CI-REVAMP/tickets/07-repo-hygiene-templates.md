# 07 — Repo hygiene: dependabot, CODEOWNERS, issue/PR templates

Status: ⬜ ready
Type: AFK

## What to build

Add the standard VEAF open-source hygiene files: `.github/dependabot.yml` (github-actions
ecosystem, weekly), `.github/CODEOWNERS`, `.github/ISSUE_TEMPLATE/` (bug report + feature request),
and `.github/pull_request_template.md`.

## Acceptance criteria

- [ ] `dependabot.yml` watches the github-actions ecosystem on a weekly cadence.
- [ ] `CODEOWNERS` routes reviews to the maintainer(s).
- [ ] Bug-report and feature-request issue templates exist.
- [ ] A pull-request template exists.

## Blocked by

None - can start immediately.

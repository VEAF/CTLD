## What to build

In the Pack <scene> command, read the number of crates created and announce it: failure (none), partial (some), or the existing message (all),
with an ERROR / WARNING log. Add the two messages and translate FR, ES, KO. Tests first in the pack spec. Then CHANGELOG, backlog index, PR.

## Acceptance criteria

- [ ] New cases fail before the change and pass after it; the existing pack cases pass unchanged.
- [ ] No crate created: failure message and ERROR log, no "packed successfully".
- [ ] Some crates created: the partial message with the counts and a WARNING log.
- [ ] Dictionaries regenerated by `merge_CTLD.ps1`, FR/ES/KO translated; luacheck clean; `busted` green; CHANGELOG entry.

# 01 — The AI cow's deployment timer reports a refused deployment

**Status:** ⬜ ready · **Type:** AFK

## Parent

[PRD — FIX-FAT-COW-DEPLOY-REFUSALS](../PRD.md). Stories 1 to 16. GitHub issue #296.

## What to build

When an AI cow lands and the deployment that follows the delay is refused, the flight is told and the log says why. The timer reads the answer of the deployment instead of throwing it away.

- **Per reason.**
  - *empty*: a dedicated message to the flight ("The Fat Cow is empty: send it home with RTB."), and a warning line in the log.
  - *airborne*, *scene*, *unknown*: the existing message "The Fat Cow FARP could not be deployed.", and a warning line that names the reason.
  - *deployed*: no message, an information line.
  - *failed*: unchanged. The scene's failure path has already told the audience; the timer adds no second message.
- **Who is told.** The flight the cow serves, and only if it still exists. The log line is written in every case, with the cow's name and the reason (the exact lines are those of the PRD, in English and untranslated).
- **Nothing else changes.** The nominal path is untouched (a cow with stock deploys with no warning and no refusal message). There is no immediate refusal in **Land here** for an empty cow, and an empty cow is not sent home when it folds its FARP.
- **The new text.** The empty-cow message is one literal passed to the translation function, naming the **RTB** command as each language's menu does. The dictionaries are regenerated by the build; French and Spanish are provided, Korean is written by the assistant and flagged for review in the pull request.
- **The documentation.** One sentence in the pilot guide (English and French), by the **Land here** command: a cow with nothing left opens no FARP, and the flight is told when the delay runs out, with the advice to send it home with **RTB**.
- **The CHANGELOG** records it under *Fixed*. No configuration key: no `configVersion` change, no catalogue shape.

## Acceptance criteria

- [ ] After the delay, an empty cow tells the flight "The Fat Cow is empty: send it home with RTB." and logs a warning that names the reason.
- [ ] A cow that is airborne, whose scene did not start, or that is no longer registered tells the flight "The Fat Cow FARP could not be deployed." and logs a warning that names the reason.
- [ ] A cow already deployed when the delay runs out tells the flight nothing and logs an information line.
- [ ] A deployment that failed (its FARP or fuel depot could not be added) gives the flight exactly one message, the scene's; the timer adds none.
- [ ] When the flight no longer exists, no message is sent and the line is logged.
- [ ] A cow with stock deploys as before, with no warning and no refusal message; the existing nominal and cancellation tests pass unchanged.
- [ ] The new cases fail before the change, for the right reason (nothing is said and nothing is logged), and pass after it.
- [ ] The dictionaries are regenerated and the new text has French and Spanish translations; the Korean one is flagged for review.
- [ ] The pilot guide (English and French) says that a cow with nothing left opens no FARP, and the `CHANGELOG` entry is there.
- [ ] `busted tests/ci/` green; luacheck clean.

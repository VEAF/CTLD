# 01 — Handle a failed parachute troop spawn

**Status:** ✅ done (PR #242) · **Type:** AFK

## Parent

[PRD — FIX-PARACHUTE-TROOPS-SPAWN-FAILURE](../PRD.md). Source: GitHub issue #235. Stories 1-9.

## What to build

When the ground spawn of parachuted troops fails at the end of the descent, log it at `ERROR`, tell the
player the troops were lost, close the parachute effect, and do not publish `OnTroopsParachuteLanded` nor
register any group. Test first (force `coalition.addGroup` to raise), then fix, then document the event
behaviour (EN + FR), add the CHANGELOG entry, and let the build add the i18n key (translate FR/ES/KO).

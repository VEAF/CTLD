## What to build

- **Docs, English and French:** pilot, mission-maker and developer pages are corrected and
  completed.
  - The Il-76 is AI-only and has no native cargo; the C-130J-30 is the only fixed-wing native-carry
    aircraft.
  - A native-carry vehicle or crate is released by DCS and tracked by CTLD (ground unload, in-flight
    parachute release that lands alive); the vehicle subsystem page no longer says the exit is a
    no-op.

    parachute: the unit is not respawned; CTLD's own parachute respawns it at its landing position.

  - Cargo created with the loadmaster tablet is ignored by CTLD.

  are corrected.
- **Roadmap:** the native bbox-exit entry is closed; follow-up entries are added — the native crate

  comments and the parachute page), the vehicle weight limit enforced for the AI only, adopting
  cargo that CTLD does not track (tablet-spawned cargo, editor crates of an unknown type) as
  generic crates, and extending `convertNativeLoadToCTLD` to vehicles.
- **Changelog:** the `[Unreleased]` entries of the lot are consolidated and consistent.
- **Finalization:** the PRD status is set to done, and the lot's index line in the backlog README
